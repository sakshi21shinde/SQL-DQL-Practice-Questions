# SQL DQL Practice Questions

## Overview
This repository contains SQL Data Query Language (DQL) practice questions completed while learning SQL. The exercises focus on retrieving, filtering, sorting, and displaying specific records from database tables.

## Topics Learned
- **SELECT** – Retrieve all columns or specific columns from a table.
- **WHERE** – Filter records based on conditions.
- **Comparison Operators** – Use `=`, `<>`, `>`, `<`, `>=`, and `<=`.
- **AND and OR** – Combine multiple conditions.
- **LIKE and NOT LIKE** – Search for patterns in text using wildcards.
- **IN** – Match values against a list of specified values.
- **BETWEEN** – Filter values within a specified range.
- **LIMIT** – Restrict the number of records returned.

## Practice Questions

### SELECT and WHERE
1. Display all records from the `branches` table.
2. Display only the branch name and branch phone number.
3. Display branches located in Mumbai.
4. Display customers born after 1 January 1998.
5. Display customers whose first name is Rahul or whose customer name is Sneha.

### Filtering and Operators
6. Display records using comparison operators.
7. Filter records using multiple conditions with `AND`.
8. Filter records using multiple conditions with `OR`.
9. Display records matching a specific value using `IN`.
10. Filter records within a specified range using `BETWEEN`.

### Pattern Matching
11. Display names starting with a particular letter using `LIKE`.
12. Display names ending with a particular letter.
13. Display names containing a specific character.
14. Display records that do not match a specified pattern using `NOT LIKE`.

### Sorting and Unique Values
15. Sort records in ascending order using `ORDER BY`.
16. Sort records in descending order.
17. Display unique values from a column using `DISTINCT`.
18. Display only a specified number of records using `LIMIT`.

- Practise retrieving specific information from database tables.
- Learn to filter and sort data efficiently.
- Improve problem-solving skills through SQL queries.
